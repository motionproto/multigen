# Multigen

Multigen makes and organizes images from written descriptions on your Mac. This repository holds Multigen's releases. The source code is private.

## Download

[Download the newest Multigen](https://github.com/motionproto/multigen/releases/latest/download/Multigen-arm64.dmg). Multigen needs a Mac with Apple silicon and macOS 13 or later. Open the disk image and drag Multigen to the Applications folder. Multigen updates itself from there.

## Report a bug

In Multigen, click the help button at the top of the window and choose Submit bug report, or choose Help > Report a Bug… in the menu bar. You can also email support@motionproto.com.
